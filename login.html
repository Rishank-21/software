Connect Firebase first

This app needs your Firebase project credentials before it can sign anyone in.

  1. Create a project at console.firebase.google.com
  2. Enable Realtime Database and Authentication › Email/Password
  3. Copy the web config into js/firebase.js
  4. Add at least one user under the Users tab
